1. MEMBER MANAGEMENT MODULE
================================================================================

🎯 PURPOSE:
-----------
Manage library members who can borrow books. Track their information, 
membership status, and borrowing history.

✨ FEATURES:
-----------

A. VIEW MEMBERS
   - Display all members in a beautiful table
   - Show: Photo, Name, Email, Phone, Member ID, Join Date, Status
   - Search by name, email, or member ID
   - Filter by membership status (Active/Inactive/Suspended)
   - Pagination for large datasets

B. ADD NEW MEMBER
   - Slide-over panel (like books)
   - Fields:
     * Profile photo upload
     * Full name *
     * Email *
     * Phone number *
     * Address
     * Date of birth
     * ID/Passport number
     * Membership type (Standard/Premium/Student)
     * Join date (auto-filled)
   - Generate unique Member ID automatically
   - Create user account for member portal access

C. EDIT MEMBER
   - Same slide-over panel
   - Update member information
   - Change membership status
   - Update photo

D. VIEW MEMBER DETAILS
   - Full profile with photo
   - Borrowing history
   - Current books borrowed
   - Fine history
   - Total books borrowed (lifetime)
   - Active/Overdue status

E. SUSPEND/ACTIVATE MEMBER
   - Toggle member status
   - Suspended members cannot borrow books
   - Show reason for suspension

F. DELETE MEMBER
   - Only if no active borrows
   - Confirmation dialog
   - Archive option (soft delete)

📊 STATISTICS:
--------------
- Total Members
- Active Members
- Members with Overdue Books
- New Members This Month

2. ISSUE BOOK MODULE
================================================================================

🎯 PURPOSE:
-----------
Allow librarians to issue books to members. Track who has which book,
issue date, due date, and expected return date.

✨ FEATURES:
-----------

A. ISSUE BOOK FORM
   - Search & Select Member
     * Search by name, email, or member ID
     * Show member photo and details
     * Check if member is active
     * Show current books borrowed count
     * Check for overdue books
     * Block if member has unpaid fines > threshold
   
   - Search & Select Book
     * Search by title, author, or ISBN
     * Show book cover image
     * Display available quantity
     * Only show books with available_quantity > 0
     * Check if same member already has this book
   
   - Issue Details
     * Issue date (auto: today)
     * Due date (default: 14 days, configurable)
     * Can extend due date
     * Add notes (optional)

B. QUICK ISSUE
   - Scan member barcode
   - Scan book barcode
   - One-click issue

C. BULK ISSUE
   - Select one member
   - Issue multiple books at once
   - Set same due date for all

D. VALIDATION RULES
   - Member must be active
   - Book must be available
   - Member cannot exceed borrow limit (e.g., 5 books max)
   - Member cannot borrow same book twice
   - Check for unpaid fines

E. AFTER ISSUE
   - Update book available_quantity (-1)
   - Create issued_books record
   - Send email/SMS notification to member
   - Print issue slip (optional)

📊 STATISTICS:
--------------
- Total Books Issued Today
- Total Active Issues
- Most Issued Book
- Most Active Borrower

3. RETURN BOOK MODULE
================================================================================

🎯 PURPOSE:
-----------
Process book returns, calculate fines for overdue books, update inventory,
and track book condition.

✨ FEATURES:
-----------

A. RETURN BOOK FORM
   - Search Options:
     * Search by Member Name/ID
     * Search by Book Title/ISBN
     * Scan barcode
   
   - Show Issued Books
     * Display all books borrowed by selected member
     * Show: Book cover, Title, Issue date, Due date, Days overdue
     * Highlight overdue books in red
     * Show calculated fine amount

B. RETURN PROCESS
   - Select book to return
   - Return date (auto: today)
   - Book condition check:
     * Good condition (no charge)
     * Damaged (charge damage fee)
     * Lost (charge replacement cost)
   
   - Fine Calculation
     * Auto-calculate overdue fine
     * Formula: (Days overdue × Fine per day)
     * Example: 3 days × $1/day = $3 fine
     * Show breakdown
   
   - Payment
     * Fine amount
     * Damage/Lost fee (if applicable)
     * Total amount
     * Payment method (Cash/Card/Online)
     * Record payment

C. BULK RETURN
   - Return multiple books at once
   - Calculate total fines
   - Single payment for all

D. AFTER RETURN
   - Update book available_quantity (+1)
   - Update issued_books status to "Returned"
   - Update book damaged/lost quantity if applicable
   - Record fine payment
   - Send return confirmation
   - Update member's borrowing history

E. BOOK CONDITION TRACKING
   - Good: Return to shelf
   - Damaged: Increment damaged_quantity, charge fee
   - Lost: Increment lost_quantity, charge replacement cost

📊 STATISTICS:
--------------
- Returns Today
- Total Active Borrows
- Total Fines Collected Today
- Average Return Time

4. OVERDUE & FINES MODULE
================================================================================

🎯 PURPOSE:
-----------
Monitor overdue books, track fines, send reminders, and manage payments.
Help librarians identify problem borrowers and books at risk.

✨ FEATURES:
-----------

A. OVERDUE BOOKS LIST
   - Display all overdue books
   - Columns:
     * Member photo & name
     * Book cover & title
     * Issue date
     * Due date
     * Days overdue (highlighted)
     * Calculated fine
     * Contact info
     * Action buttons
   
   - Sorting:
     * Most overdue first
     * Highest fine first
     * By member
     * By book
   
   - Filters:
     * Overdue range (1-7 days, 7-14 days, 14+ days)
     * Fine range
     * Member status

B. FINE CALCULATION
   - Configurable fine structure:
     * Fine per day: $1 (default)
     * Grace period: 0 days
     * Maximum fine cap: $50
     * Different rates for different membership types
   
   - Auto-calculate daily
   - Formula: MIN((Today - Due Date) × Fine Rate, Max Cap)

C. SEND REMINDERS
   - Manual: Select members and send
   - Automatic: 
     * 1 day before due date (reminder)
     * On due date (last day notice)
     * 1 day overdue (overdue notice)
     * 7 days overdue (urgent notice)
   
   - Channels:
     * Email
     * SMS
     * In-app notification
   
   - Template: 
     "Dear [Name], your book '[Title]' is overdue by [Days] days. 
     Fine: $[Amount]. Please return soon."

D. PAYMENT MANAGEMENT
   - Record fine payments
   - Partial payments allowed
   - Payment history
   - Receipt generation
   - Payment methods tracking

E. FINE REPORTS
   - Total fines outstanding
   - Fines collected (today/week/month)
   - Top debtors
   - Fine trends chart

F. MEMBER RESTRICTIONS
   - Auto-suspend if fine > $20
   - Cannot borrow new books until fine paid
   - Show warning when trying to issue

📊 STATISTICS:
--------------
- Total Overdue Books
- Total Outstanding Fines
- Fines Collected Today
- Members with Unpaid Fines
- Average Days Overdue

5. DATABASE STRUCTURE
================================================================================

TABLES NEEDED:
--------------

A. members
   - member_id (PK, AUTO_INCREMENT)
   - full_name VARCHAR(100)
   - email VARCHAR(100) UNIQUE
   - phone VARCHAR(20)
   - address TEXT
   - date_of_birth DATE
   - id_number VARCHAR(50)
   - profile_photo VARCHAR(255)
   - membership_type ENUM('standard', 'premium', 'student')
   - join_date DATE
   - status ENUM('active', 'inactive', 'suspended')
   - max_books_allowed INT DEFAULT 5
   - created_at TIMESTAMP
   - updated_at TIMESTAMP

B. issued_books
   - issue_id (PK, AUTO_INCREMENT)
   - book_id (FK -> books)
   - member_id (FK -> members)
   - issue_date DATE
   - due_date DATE
   - return_date DATE (NULL if not returned)
   - status ENUM('Issued', 'Returned', 'Lost')
   - book_condition_on_return ENUM('Good', 'Damaged', 'Lost')
   - fine_amount DECIMAL(10,2) DEFAULT 0
   - fine_paid DECIMAL(10,2) DEFAULT 0
   - notes TEXT
   - issued_by INT (FK -> users)
   - returned_by INT (FK -> users)
   - created_at TIMESTAMP

C. fine_payments
   - payment_id (PK, AUTO_INCREMENT)
   - issue_id (FK -> issued_books)
   - member_id (FK -> members)
   - amount DECIMAL(10,2)
   - payment_method ENUM('cash', 'card', 'online')
   - payment_date DATETIME
   - receipt_number VARCHAR(50)
   - notes TEXT
   - recorded_by INT (FK -> users)

D. notifications
   - notification_id (PK, AUTO_INCREMENT)
   - member_id (FK -> members)
   - type ENUM('reminder', 'overdue', 'payment')
   - message TEXT
   - sent_at DATETIME
   - status ENUM('pending', 'sent', 'failed')

E. library_settings
   - setting_id (PK)
   - setting_key VARCHAR(50) UNIQUE
   - setting_value VARCHAR(255)
   - description TEXT
   
   Settings:
   - fine_per_day: 1.00
   - grace_period_days: 0
   - max_fine_amount: 50.00
   - default_borrow_days: 14
   - max_books_per_member: 5
   - fine_threshold_for_suspension: 20.00
