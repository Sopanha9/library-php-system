💻 CODE EXAMPLES
================================================================================

1. SIMPLE SUCCESS ALERT
------------------------
Swal.fire({
  icon: 'success',
  title: 'Success!',
  text: 'Operation completed successfully.',
  confirmButtonText: 'Great!'
});


2. ERROR ALERT
--------------
Swal.fire({
  icon: 'error',
  title: 'Error',
  text: 'Something went wrong. Please try again.',
  confirmButtonText: 'OK'
});


3. CONFIRMATION DIALOG (Delete/Destructive Action)
---------------------------------------------------
Swal.fire({
  title: 'Are you sure?',
  text: 'This action cannot be undone!',
  icon: 'warning',
  showCancelButton: true,
  confirmButtonText: 'Yes, delete it!',
  cancelButtonText: 'Cancel',
  reverseButtons: true
}).then((result) => {
  if (result.isConfirmed) {
    // User confirmed - proceed with action
    // Perform delete/update
    
    Swal.fire({
      icon: 'success',
      title: 'Deleted!',
      text: 'Record has been deleted.',
      confirmButtonText: 'OK'
    });
  }
  // If cancelled, nothing happens (modal closes)
});


4. TOAST NOTIFICATION (Non-blocking, auto-dismiss)
---------------------------------------------------
const Toast = Swal.mixin({
  toast: true,
  position: 'top-end',
  showConfirmButton: false,
  timer: 3000,
  timerProgressBar: true,
  didOpen: (toast) => {
    toast.addEventListener('mouseenter', Swal.stopTimer)
    toast.addEventListener('mouseleave', Swal.resumeTimer)
  }
});

Toast.fire({
  icon: 'success',
  title: 'Saved successfully!',
  text: 'Your changes have been saved.'
});


5. INFO/QUESTION DIALOG
------------------------
Swal.fire({
  icon: 'info',
  title: 'Information',
  text: 'Here is some important information for you.',
  confirmButtonText: 'Got it'
});

// OR for questions
Swal.fire({
  title: 'Activate Member?',
  text: 'Are you sure you want to activate this member?',
  icon: 'question',
  showCancelButton: true,
  confirmButtonText: 'Yes, activate!',
  cancelButtonText: 'No, cancel'
});


6. WITH CUSTOM HTML CONTENT
----------------------------
Swal.fire({
  title: 'Book Returned!',
  icon: 'success',
  html: `
    <div class="text-left">
      <p><strong>Member:</strong> John Smith</p>
      <p><strong>Book:</strong> The Great Gatsby</p>
      <p><strong>Fine:</strong> 5.00 Riel</p>
      <p><strong>Paid:</strong> 5.00 Riel</p>

  `,
  confirmButtonText: 'OK'
});


================================================================================
🎯 WHEN TO USE EACH TYPE
================================================================================

SUCCESS ALERT:
--------------
Use when:
✓ Record successfully added (book, member)
✓ Record successfully updated
✓ Record successfully deleted
✓ Operation completed without errors
✓ Settings saved

Example: "Book Added Successfully!"


ERROR ALERT:
------------
Use when:
✓ Validation failed
✓ Database error
✓ Permission denied
✓ Network/fetch error
✓ Required field missing

Example: "Unable to add book. ISBN already exists."


WARNING/CONFIRM:
----------------
Use when:
✓ Deleting records (cannot be undone)
✓ Suspending members
✓ Irreversible actions
✓ Data loss risk

Example: "Delete this member? This cannot be undone."


INFO:
-----
Use when:
✓ Explaining rules/settings
✓ Showing library policies
✓ Displaying help text
✓ Non-critical information

Example: "Default borrow period is 14 days."


QUESTION:
---------
Use when:
✓ Status changes (active/inactive)
✓ Yes/No decisions
✓ Optional confirmations
✓ Non-destructive choices

Example: "Activate this member?"


TOAST:
------
Use when:
✓ Quick feedback needed
✓ Non-critical updates
✓ Status changes (not destructive)
✓ Background operations complete
✓ Don't want to block user workflow

Example: "Status updated!" (appears in corner, auto-dismisses)

================================================================================
🐛 TROUBLESHOOTING
================================================================================

Issue: Alerts appear but without glassmorphism styling
Solution: Clear browser cache and hard refresh (Ctrl+F5)

Issue: Buttons not showing blue gradient
Solution: Check that includes/header.php is included in the page

Issue: Toast not appearing
Solution: Verify Toast.mixin() is called before Toast.fire()

Issue: Confirm dialog not waiting for user response
Solution: Use .then((result) => { if (result.isConfirmed) { ... } })

Issue: Text overlapping or layout broken
Solution: Add 'text' property for simple messages, 'html' for complex content
