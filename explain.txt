1. THE PROBLEM WE HAD
================================================================================

SCENARIO:
---------
You're on the admin dashboard: http://localhost:8080/library-php-system/admin/dashboard.php
You click "Manage Books" → Works fine! Takes you to /books/manage.php
You click "Dashboard" again → BROKEN! URL stays at /books/manage.php

WHY IT BROKE:
-------------
The sidebar was using RELATIVE PATHS like:
  - <a href="dashboard.php">Dashboard</a>
  - <a href="../books/manage.php">Manage Books</a>

Relative paths work differently depending on WHERE YOU ARE in the file system.

ANALOGY:
--------
Imagine you're in a building and someone says "Go up one floor."
  - If you're on Floor 1, you go to Floor 2 ✅
  - If you're on Floor 5, you go to Floor 6 ❌ (Wrong destination!)

That's the problem with relative paths - they depend on your current location!

2. UNDERSTANDING FILE PATHS
================================================================================

RELATIVE PATH:
--------------
Definition: A path that starts from your CURRENT location.

Examples:
  From /admin/dashboard.php:
    - "dashboard.php" → Looks in /admin/ → /admin/dashboard.php ✅
    - "../books/manage.php" → Go up (..), then into books → /books/manage.php ✅
  
  From /books/manage.php:
    - "dashboard.php" → Looks in /books/ → /books/dashboard.php ❌ (Doesn't exist!)
    - "../admin/dashboard.php" → Go up, then into admin → /admin/dashboard.php ✅

SYMBOLS:
  . (dot) = Current directory
  .. (double dot) = Parent directory (go up one level)
  / (forward slash) = Directory separator


ABSOLUTE PATH:
--------------
Definition: A path that starts from the ROOT of the website.
Always works the same way, no matter where you are!

Structure:
  /library-php-system/admin/dashboard.php
  └─────┬──────────┘ └─┬─┘ └────┬─────┘
    Root/Base      Folder  Filename

Examples:
  From ANYWHERE:
    - "/library-php-system/admin/dashboard.php" → /admin/dashboard.php ✅
    - "/library-php-system/books/manage.php" → /books/manage.php ✅
    - Always works! No confusion!


COMPARISON:
-----------
╔═══════════════════╦══════════════════════╦════════════════════════════╗
║   Current Page    ║   Relative Path      ║      Absolute Path         ║
╠═══════════════════╬══════════════════════╬════════════════════════════╣
║ /admin/           ║ dashboard.php        ║ /library-php-system/       ║
║   dashboard.php   ║ → /admin/dashboard   ║   admin/dashboard.php      ║
║                   ║ ✅ Works             ║ ✅ Always works            ║
╠═══════════════════╬══════════════════════╬════════════════════════════╣
║ /books/           ║ dashboard.php        ║ /library-php-system/       ║
║   manage.php      ║ → /books/dashboard   ║   admin/dashboard.php      ║
║                   ║ ❌ 404 Error!        ║ ✅ Always works            ║
╚═══════════════════╩══════════════════════╩════════════════════════════╝

3. THE SOLUTION EXPLAINED
================================================================================

WHAT WE DID:
------------
Changed the sidebar.php to use ABSOLUTE PATHS for all navigation links.

BEFORE (Broken):
----------------
<?php
$menu_items = [
  ['label' => 'Dashboard', 'url' => 'dashboard.php'],
  ['label' => 'Manage Books', 'url' => '../books/manage.php'],
  ['label' => 'Logout', 'url' => '../auth/logout.php']
];
?>

Problems:
  - Relative paths break when you change directories
  - Each page needs different paths
  - Hard to maintain


AFTER (Fixed):
--------------
<?php
$base_path = '/library-php-system';
$role = $_SESSION['role'] ?? 'member';

$menu_items = [
  ['label' => 'Dashboard', 'url' => $base_path . '/' . $role . '/dashboard.php'],
  ['label' => 'Manage Books', 'url' => $base_path . '/books/manage.php'],
  ['label' => 'Logout', 'url' => $base_path . '/auth/logout.php']
];
?>

Benefits:
  ✅ Works from any page
  ✅ Consistent URLs
  ✅ Easy to maintain
  ✅ Smart dashboard routing based on user role

4. CODE BREAKDOWN LINE-BY-LINE
================================================================================

LINE 1: Set the Base Path
--------------------------
$base_path = '/library-php-system';

EXPLANATION:
  - This is the ROOT of your application
  - Starts with / to make it absolute
  - Change this if your app is in a different folder
  - Examples:
      If app is at root: $base_path = '';
      If in subfolder: $base_path = '/my-app';


LINE 2-3: Detect Current Location
----------------------------------
$current_page = basename($_SERVER['PHP_SELF']);
$current_dir = basename(dirname($_SERVER['PHP_SELF']));

EXAMPLE BREAKDOWN:
  $_SERVER['PHP_SELF'] = '/library-php-system/admin/dashboard.php'
                         └──────────────────┘└───┘└──────────┘
                          Full path          Folder  Filename
  
  Step 1: dirname($_SERVER['PHP_SELF'])
    → '/library-php-system/admin'
    (Gets the directory path)
  
  Step 2: basename(dirname($_SERVER['PHP_SELF']))
    → 'admin'
    (Gets just the folder name)
  
  Step 3: basename($_SERVER['PHP_SELF'])
    → 'dashboard.php'
    (Gets just the filename)

RESULT:
  $current_page = 'dashboard.php'
  $current_dir = 'admin'


LINE 4-5: Smart Dashboard Routing
----------------------------------
$role = $_SESSION['role'] ?? 'member';
$dashboard_url = $base_path . '/' . $role . '/dashboard.php';

THE ?? OPERATOR (Null Coalescing):
  Syntax: $variable ?? 'default_value'
  Meaning: If $variable exists and is not null, use it. Otherwise, use default.
  
  Example:
    $_SESSION['role'] = 'admin';
    $role = $_SESSION['role'] ?? 'member';
    → $role = 'admin' ✅
    
    $_SESSION['role'] = null;
    $role = $_SESSION['role'] ?? 'member';
    → $role = 'member' ✅

STRING CONCATENATION:
  $base_path . '/' . $role . '/dashboard.php'
  
  If $role = 'admin':
    '/library-php-system' . '/' . 'admin' . '/dashboard.php'
    → '/library-php-system/admin/dashboard.php'
  
  If $role = 'librarian':
    '/library-php-system' . '/' . 'librarian' . '/dashboard.php'
    → '/library-php-system/librarian/dashboard.php'


LINE 6-15: Creating Menu Items Array
-------------------------------------
$menu_items = [
  [
    'icon' => 'fa-book', 
    'label' => 'Manage Books', 
    'url' => $base_path . '/books/manage.php',
    'page' => 'manage.php',
    'dir' => 'books'
  ],
  // ... more items
];

STRUCTURE:
  - Each menu item is an ASSOCIATIVE ARRAY (key => value pairs)
  - 'url' → Full absolute path for the link
  - 'page' → Just the filename (used for active detection)
  - 'dir' → Just the folder name (used for active detection)

WHY SEPARATE 'page' AND 'dir'?
  We need to know if the current page matches this menu item to highlight it!


LINE 16-22: Active Menu Detection
----------------------------------
$is_active = false;
if (isset($item['dir'])) {
  $is_active = ($current_dir === $item['dir'] && $current_page === $item['page']);
} else {
  $is_active = ($current_page === $item['page']);
}

LOGIC EXPLANATION:

Case 1: Menu items with folders (Books, Members, etc.)
  Check BOTH folder AND filename must match
  
  Example:
    Current location: /books/manage.php
      → $current_dir = 'books'
      → $current_page = 'manage.php'
    
    Menu item: ['dir' => 'books', 'page' => 'manage.php']
    
    Check: ('books' === 'books') AND ('manage.php' === 'manage.php')
           ✅ TRUE              AND  ✅ TRUE
    Result: $is_active = true → Menu item is highlighted!

Case 2: Dashboard (no 'dir' key)
  Only check the filename
  
  Example:
    Current location: /admin/dashboard.php
      → $current_page = 'dashboard.php'
    
    Menu item: ['page' => 'dashboard.php']  (no 'dir')
    
    Check: 'dashboard.php' === 'dashboard.php'
    Result: $is_active = true → Dashboard is highlighted!


LINE 23-26: Rendering the Link
-------------------------------
<a href="<?= $item['url'] ?>" 
   class="<?= $is_active ? 'bg-white/20 shadow-lg' : 'hover:bg-white/10' ?>">
  <?= $item['label'] ?>
</a>

TERNARY OPERATOR:
  condition ? value_if_true : value_if_false
  
  Example:
    $is_active = true;
    $class = $is_active ? 'active' : 'inactive';
    → $class = 'active'
    
    $is_active = false;
    $class = $is_active ? 'active' : 'inactive';
    → $class = 'inactive'

IN OUR CODE:
  If $is_active is true:
    → class="bg-white/20 shadow-lg" (highlighted style)
  
  If $is_active is false:
    → class="hover:bg-white/10" (normal style)

6. KEY PHP FUNCTIONS
================================================================================

basename($path)
---------------
Purpose: Extracts the filename from a path
Returns: String (just the filename)

Examples:
  basename('/library-php-system/admin/dashboard.php')
  → 'dashboard.php'
  
  basename('/var/www/html/index.php')
  → 'index.php'
  
  basename('/images/photo.jpg')
  → 'photo.jpg'


dirname($path)
--------------
Purpose: Extracts the directory path (removes filename)
Returns: String (path without filename)

Examples:
  dirname('/library-php-system/admin/dashboard.php')
  → '/library-php-system/admin'
  
  dirname('/var/www/html/index.php')
  → '/var/www/html'
  
  dirname('/images/photo.jpg')
  → '/images'


isset($variable)
----------------
Purpose: Checks if a variable is set and not null
Returns: Boolean (true/false)

Examples:
  $name = 'John';
  isset($name) → true
  
  $age = null;
  isset($age) → false
  
  isset($undefined) → false


$_SERVER['PHP_SELF']
--------------------
Purpose: Contains the filename of the currently executing script
Type: Superglobal array

Example:
  If URL is: http://localhost/library-php-system/admin/dashboard.php
  $_SERVER['PHP_SELF'] = '/library-php-system/admin/dashboard.php'


Comparison Operators
--------------------
=== (Strict equality)
  - Checks if values AND types are equal
  - 5 === 5 → true
  - 5 === '5' → false (different types)
  - 'admin' === 'admin' → true

== (Loose equality)
  - Checks if values are equal (type conversion)
  - 5 == '5' → true
  - 0 == false → true
  - 'admin' == 'admin' → true


Boolean Operators
-----------------
&& (AND)
  - Both conditions must be true
  - true && true → true
  - true && false → false

|| (OR)
  - At least one condition must be true
  - true || false → true
  - false || false → false

! (NOT)
  - Inverts the boolean value
  - !true → false
  - !false → true

7. BEST PRACTICES
================================================================================

✅ DO:
------
1. Use absolute paths for navigation menus
   - Consistent behavior across all pages
   - Easier to debug

2. Store base path in a configuration file or constant
   define('BASE_PATH', '/library-php-system');
   
3. Use meaningful variable names
   $current_page (clear) vs $cp (unclear)

4. Add comments for complex logic
   // Check if both directory and filename match
   $is_active = ($current_dir === $item['dir'] && ...);

5. Use strict comparison (===) for security
   - Prevents type juggling vulnerabilities
   - More predictable behavior

6. Validate user input and session data
   $role = $_SESSION['role'] ?? 'member';


❌ DON'T:
---------
1. Mix relative and absolute paths
   - Confusing and error-prone

2. Hardcode paths in multiple places
   - Use variables/constants instead

3. Use loose comparison (==) for user data
   if ($_SESSION['role'] == 'admin') // Can be bypassed!
   Use: if ($_SESSION['role'] === 'admin')

4. Forget to handle edge cases
   - What if session is empty?
   - What if path doesn't exist?

5. Use global variables unnecessarily
   - Pass data through function parameters instead


================================================================================
8. COMMON MISTAKES TO AVOID
================================================================================

MISTAKE #1: Forgetting the Leading Slash
-----------------------------------------
❌ Wrong:
  $url = 'library-php-system/admin/dashboard.php';
  (This is actually relative!)

✅ Correct:
  $url = '/library-php-system/admin/dashboard.php';
  (Absolute path from root)


MISTAKE #2: Using == Instead of ===
------------------------------------
❌ Dangerous:
  if ($_SESSION['role'] == 'admin') {
    // Attacker could bypass with role=1 (1 == 'admin' is true!)
  }

✅ Safe:
  if ($_SESSION['role'] === 'admin') {
    // Only exact string 'admin' passes
  }


MISTAKE #3: Not Handling Missing Session Data
----------------------------------------------
❌ Crashes:
  $url = '/app/' . $_SESSION['role'] . '/dashboard.php';
  // Error if $_SESSION['role'] doesn't exist!

✅ Safe:
  $role = $_SESSION['role'] ?? 'member';
  $url = '/app/' . $role . '/dashboard.php';
  // Always has a default value


MISTAKE #4: Hardcoding Paths Everywhere
----------------------------------------
❌ Hard to maintain:
  File 1: <a href="/my-app/admin/dashboard.php">
  File 2: <a href="/my-app/books/manage.php">
  File 3: <a href="/my-app/logout.php">
  // If you rename 'my-app', you must change 50+ files!

✅ Easy to maintain:
  Config: $base_path = '/my-app';
  File 1: <a href="<?= $base_path ?>/admin/dashboard.php">
  File 2: <a href="<?= $base_path ?>/books/manage.php">
  // Change once in config, works everywhere!


MISTAKE #5: Not Testing from Different Pages
---------------------------------------------
Always test navigation from:
  ✓ Dashboard
  ✓ Books management
  ✓ Members management
  ✓ Every major section

If it works from one page but not another, you probably have a relative path issue!
