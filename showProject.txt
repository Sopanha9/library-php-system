================================================================================
⚠️ COMMON ISSUES & SOLUTIONS
================================================================================

Issue 1: Images not uploading
Solution: Check uploads/books and uploads/members folders exist with write permissions

Issue 2: Database connection error
Solution: Verify WAMP is running, check config/db.php credentials

Issue 3: Search not working
Solution: Clear browser cache, check JavaScript console for errors

Issue 4: Glassmorphism not showing
Solution: Ensure includes/header.php is loaded, check browser supports backdrop-filter

Issue 5: Fine calculation wrong
Solution: Check library_settings table in database for correct values
